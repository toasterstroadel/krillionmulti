      How it works

      1. Each prompt asks you to name something. You get one answer.
      2. Obvious answers barely count. Rare but correct ones count a lot.
      3. Today's dive is seven prompts at 25 seconds each, the same set all day.
      4. Endless dive starts you with 40 seconds of air. Deeper answers refill more air. The air only runs while a prompt is open.
      5. In a room, a round is seven prompts on a shared clock: 25 seconds to answer, then a short reveal of everyone's answers and the standings.
